# Xixify Coding Standards

## General Principles
1. **Clean & Self-Documenting**: Write explicit variable and function names.
2. **Modular Architecture**: Separate logic, styles, and markup. Keep functions focused on a single task.
3. **No Code Duplication (DRY)**: Abstract shared utilities into helper modules.
4. **Error Handling**: Always handle API errors and invalid inputs gracefully with clear UI feedback.

## Languages
- **JavaScript**: Modern ES6+ syntax (`const`/`let`, arrow functions, async/await). Avoid global variable pollution.
- **PHP**: PHP 7.4+/8.x, PSR-12 coding style, type hints.
- **CSS**: CSS custom properties for tokens, BEM naming convention or utility-first Tailwind classes.
