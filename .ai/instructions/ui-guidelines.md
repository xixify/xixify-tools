# Xixify UI Guidelines

## Aesthetics & Inspiration
- **Style**: Minimalist, Apple / Linear / Vercel inspired.
- **Layout**: Mobile-first, whitespace-driven layout containers.
- **Components**: Rounded corners (`8px` to `12px`), 1px subtle borders (`#E5E7EB` / `#27272A`), clean micro-interactions.
- **Colors**: Dark mode / light mode support. High contrast text for accessibility.
- **Typography**: Clean sans-serif stack (`Inter`, `-apple-system`, `sans-serif`).
