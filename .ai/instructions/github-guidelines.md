# GitHub Guidelines

## Repository Checklist
Every published tool repository must include:
- `README.md` (with badges, demo link, screenshots, setup instructions).
- `LICENSE` (MIT License for open-source tools; GPLv2+ for WP plugins).
- `CHANGELOG.md` (recording version updates).
- `.gitignore` (excluding node_modules, temp files, secrets).
- `CONTRIBUTING.md` (community contribution rules).

## Git Commit Standards
Use conventional commits:
- `feat: add schema generator tool`
- `fix: resolve image compression memory limit issue`
- `docs: update deployment guide`
