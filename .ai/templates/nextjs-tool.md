# Next.js Web Tool Blueprint

## Tech Stack & Architecture
- Framework: Next.js App Router
- Styling: Tailwind CSS v4
- Deployment: Vercel / Static Export for WP Embedding
- SEO: Built-in `metadata` object & OpenGraph helpers

## File Layout
```
tools/web-apps/<tool-name>/
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── components/

│   ├── ToolCard.tsx
│   └── Footer.tsx
├── package.json
└── README.md
```
