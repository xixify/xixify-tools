# Xixify WordPress Plugin Boilerplate

A clean, lightweight starter template for building WordPress plugins under Xixify Tools.

## Setup Instructions

1. Copy this directory to `tools/wordpress-plugins/<your-plugin-name>`.
2. Rename `wp-plugin-boilerplate.php` to `<your-plugin-name>.php`.
3. Update header comments in PHP file and metadata in `readme.txt`.
