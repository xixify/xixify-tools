== Description ==
Xixify Partnership & Financial Tracker is a custom WordPress plugin built for managing joint agency accounts (Xixify × DevPify). It calculates 50/50 net profit splits between partners, tracks advance payments and dues, and provides shortcode embedding for client progress views.

== Installation ==
1. Upload the plugin folder to `/wp-content/plugins/xixify-partnership-portal/`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access 'Xixify Accounts' from the WP Admin sidebar to manage projects and payments.
4. Add shortcode `[xixify_partnership_portal]` on any front-end page to display client progress.
